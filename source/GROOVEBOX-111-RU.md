# Groovebox 0.11.1 beta — запись и правка с клавиш

## На самом FM-1

**Записать партию:** выбрать дорожку через ALGO, нажать REC, сыграть ноты/барабаны. Без PLAY курсор переходит после отпускания клавиш. С PLAY запись идёт в ритм. В драмке 16 белых клавиш соответствуют 16 звукам; несколько одновременно записываются в один шаг.

**Исправить конкретный шаг:** открыть SEQ, выбрать шаг K1, удерживать EDIT и нажимать клавиши. Нота/удар добавляется; повтор той же клавиши убирает её. Курсор остаётся на месте. До четырёх нот мелодии и до всех 16 барабанов в одном шаге. При входе в такую правку активная запись завершается. Короткое EDIT без клавиш по-прежнему открывает синтез; EDIT + OCT−/+ — отмена/повтор.

K1 выбирает шаг на всех трёх страницах SEQ. PRESET переключает банки по 16 шагов. Удержание SEQ показывает сам пианоролл; белые клавиши переключают 16 шагов выбранной партии. SEQ + EDIT удаляет шаг; SEQ + REC очищает партию; SEQ + последняя чёрная очищает весь трек.

Чёрные клавиши **без удержания SEQ**, на шестой дорожке и странице SEQ:

| Клавиша слева | Действие |
|---|---|
| 1 / 2 | Предыдущий / следующий шаг в пределах длины выбранной партии |
| 3 | Пауза: убрать выбранный барабан в этом шаге и перейти дальше; REC остаётся включённым |
| 4 | Удалить выбранный барабан в текущем шаге |
| 5 / 6 | Отмена / повтор |
| 7–10 | Банки 1–4, сохраняя положение внутри банка |
| 11 | Включить/выключить выбранный барабан в текущем шаге |

Перед переходом отпусти звучащие клавиши. Для сохранения проекта — SAVE.

## В эмуляторе

Кнопка «Правка с клавиш · EDIT» открывает SEQ и удерживает EDIT. Нажимай подписанные пэды или ноты, выбирай шаг стрелками рядом с ней. Повторное нажатие кнопки выключает режим.

На дорожке 6 клавиши ПК `A S D F G H J K L ; ' \ Z X C V` играют 16 пэдов. Стрелки в SEQ выбирают шаг. Пробел — PLAY, R — REC. На мелодических дорожках сохранена обычная раскладка фортепиано.

## В веб-редакторе

Клик по клетке мелодического пианоролла добавляет/убирает ноту, клик в другой строке того же шага добавляет аккорд. Перетаскивание вправо задаёт длину. Колесо прокручивает высоты без скачка обзора после каждого клика. Delete очищает выбранный шаг. Заголовок и левый край не ставят случайных нот.

Драм-пэды и клавиши ПК используют одну карту звуков. Нажатый пэд не пересоздаётся обновлениями сетки. Клавиатура ПК работает и после нажатия кнопки REC.

## Проверки

`python -X utf8 tests/run_groovebox_audit.py --build` собирает прошивку и полный C-эмулятор. `tests/test_keyboard_roll.mjs` проверяет четырёхнотные аккорды, их удаление и переполнение, неподвижный курсор, все 16 драм-пэдов, паузы, навигацию, отмену, SAVE/перезапуск и K1 на каждой странице. Проверяется и быстрая цепочка SEQ → EDIT → клавиша через настоящий AudioWorklet.

Также сохранены проверки аудио, MIDI, старых проектов, flash-журнала и установщика из 0.11.0. [Отчёт](../emulator/audit.json) содержит контрольные суммы. Физический FM-1 не прошивался и аппаратные задержки ещё не проверены. Сэмплер остаётся отдельным.
