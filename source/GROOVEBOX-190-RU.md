# Groovebox 0.19.0 beta: вкладка «Система»

**GLO три раза быстро** (не дольше 0,35 с между нажатиями) открывает отдельную вкладку **«СИСТЕМА»**. Там четыре страницы, ручки K1–K4 меняют настройки. **GLO** листает страницы, кнопка другого раздела (HOME, FX, SEL, ENV, LFO, EDIT, ARP, SEQ) закрывает вкладку и делает своё обычное действие. Обычное листание настроек GLO в своём темпе вкладку не открывает.

| Страница | K1 | K2 | K3 | K4 | Картинка |
|---|---|---|---|---|---|
| 1 MIDI | MIDI ВХОД: по каналам / ОМНИ | TRS В USB | ПРИЕМ PC | ПРИЕМ CC | порты USB IN, USB OUT, TRS IN со счётчиками и миганием |
| 2 СИНХРО | синхронизация (внутр. / USB, TRS) | выход MIDI clock | MIDI-режим | DAW-транспорт | доли такта, темп |
| 3 ЯДРА | CPU1 сейчас | CPU1 ПРИ СТАРТЕ | выход % | лимитер | CPU0 / CPU1, нагрузка |
| 4 ПАНЕЛЬ | подсветка | клавиши (кривая силы) | при запуске | заставка | кривая силы, подсветка |

## Новые настройки

- **MIDI ВХОД: ОМНИ.** Ноты с любого MIDI-канала играют выбранную дорожку. Удобно для внешней клавиатуры: переключаешь дорожку ALGO и играешь, без настройки каналов. По умолчанию «по каналам», как раньше. В режиме DAW Controller не действует.
- **TRS В USB.** Всё, что приходит в TRS-вход (DIN-клавиатура, драм-машина, clock), уходит дальше в компьютер по USB. FM-1 работает как MIDI-интерфейс. По умолчанию выключено.
- **ПРИЕМ PC / ПРИЕМ CC.** Можно игнорировать входящие Program Change (DAW не будет перещёлкивать пресеты) и CC (ручки внешнего контроллера не трогают звук). All Notes Off принимается всегда.
- **CPU1 ПРИ СТАРТЕ.** Второе ядро (вывод и лимитер) включается сразу при загрузке, а не только вручную на сеанс. При каждом старте ядро проходит самопроверку. Если старт, проверка или работа ядра не удались, прошивка сама выключает этот пункт (сохраняется по SAVE) и работает на одном ядре. Пункт **экспериментальный**, по умолчанию выключен.

Хранение: настройки записываются после прежних 112 байт системных настроек, в тот же объект. Старые файлы настроек загружаются со значениями по умолчанию. Редактор получает их в ответе на команду 28 (байты 122–126) и меняет командой 29 (номера 15–19). В веб-редакторе они в «Настройках».

## USB host

USB host в этой версии сделать нельзя. USB-C порт FM-1 и платформа прошивки работают только как USB-устройство: MIDI и аудиовход к компьютеру. Подключить USB-клавиатуру прямо в FM-1 нельзя. Для внешней клавиатуры есть TRS-вход и новая настройка «TRS в USB».

## Проверки

- Новый `test_system_190` (8 проверок):
  - три нажатия GLO открывают вкладку, ручки меняют системные настройки, страница под вкладкой не меняется;
  - GLO листает страницы, другой раздел закрывает вкладку;
  - два нажатия и медленные нажатия вкладку не открывают;
  - омни-вход: нота на 16-м канале играет выбранную дорожку;
  - TRS → USB пересылает сообщение, а выключенный не пересылает;
  - фильтры PC и CC работают;
  - всё сохраняется по SAVE и переживает перезапуск, CPU1 при старте запускает ядро и проходит самопроверку;
  - недопустимые номера и значения отклоняются.
- `test_lights_grid` теперь листает GLO в обычном темпе.
- Инварианты фаззера: новые поля 0/1, номер страницы вкладки.
- Полный аудит + 200 сессий фаззинга под ASan/UBSan.
- Образ 260 700 Б, RAM 65 800 из 98 304 Б.

Физический FM-1 не прошивался.
