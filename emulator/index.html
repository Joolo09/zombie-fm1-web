Твой первый паттерн

  1. SEQ — 16 белых клавиш добавляют и выбирают шаги.
  2. Нажми шаг, ручками измени ноту, силу и длину.
  3. EDIT — удали выбранную ноту. PLAY — послушай.
  4. REC на главной — отсчёт 1 такт, потом запись по кругу. На странице SEQ — запись по шагам.
  5. SAVE — сохрани проект перед перезапуском.

Всё под рукой

Другая дорожка
Энкодер ALGO. Драмка — шестая.
Запись в ритм (0.16)
REC на любой странице, кроме SEQ: отсчёт 1 такт, затем петля играет и пишет с наложением, метроном щёлкает. REC ещё раз — конец дубля, PLAY во время отсчёта — старт сразу. Слой REC (REC + HOME): ОТСЧЕТ (выкл / 1 / 2 такта), КЛИК при записи, CLEAR.
Живой экран и заставка (0.18)
Зомби качает головой в такт, ноты разлетаются искрами. Минута без касаний — заставка; любая кнопка будит, удержание HOME на заставке — следующая (ночь, синтвейв, матрица, лого). HOME дважды — «О системе». Выбрать или выключить: GLO, стр. 5, K4. Пресеты 97–128 — новый банк ZMB.
Число шагов
Удерживай SEQ и крути K1: 1–64 шага дорожки; на драмке одна длина для всех звуков.
Исправить ноты с клавиш
На странице SEQ удерживай EDIT и нажимай клавиши: в мелодии добавляй/убирай ноты выбранного шага. В драмке EDIT + белая стирает шаг выбранного звука. REC не нужен. Кнопка «Правка с клавиш» удержит EDIT за тебя.
OP-кнопки драмки на SEQ
OP1–OP6 выбирают звук; PITCH/GLOBAL листают группы по 6 звуков; MONO/POLY — отмена/повтор. Без REC белые включают и выключают шаги (при отпускании); зажми шаг и крути K3/K4 — сила и дробь этого шага. С REC играют 16 пэдов. EDIT + белая стирает шаг. Крайняя правая верхняя клавиша: удалить (REC: пауза).
Удалить шаг
Коротко EDIT: выбранная нота. SEQ + EDIT: весь шаг.
Очистить партию
Удерживай SEQ и нажми REC.
Очистить весь трек
SEQ + последняя чёрная клавиша.
Вернуть изменение
EDIT + OCT−. Повторить — EDIT + OCT+.
Лад (0.17)
GLO, страница 2: ЛАД и ТОНИКА. Клавиши попадают в тональность, ноты лада слабо подсвечены.
Зажми шаг мелодии (0.17)
На SEQ зажми шаг и крути K1 нота, K2 сила, K3 длина, K4 гейт. Драмка: K2 шанс, K3 сила, K4 дробь.
SEQ-инструменты (0.17)
Держи SEQ и крути PRESET до 4-й страницы: K1 удары, K2 сдвиг, K3 шагов. Чёрные 1–4: ЭВКЛИД, СЛУЧ./БИТ, ПОЛОВИНА, COOK. Отмена: отпусти SEQ, EDIT + OCT−.
MIDI clock (0.17)
GLO, страница 5: ВЫХОД CLOCK.
SAVE во время игры
Музыка не останавливается: проект сохранится после STOP.
Новый пустой проект
Удерживай HOME, дважды нажми 15-ю белую клавишу.
Это код самой прошивки.

Звук, экран, меню, кнопки и сохранение выполняются на C, как в FM-1. Физические датчики, USB-прошивка и загрузчик здесь моделируются. Сэмплер пока остаётся отдельным.

На ПК: A W S E D F T G Y H U J K — ноты. В драмке A S D F G H J K L ; ' \ Z X C V — 16 белых клавиш: без REC шаги, с REC пэды; стрелки ←/→ выбирают шаг. Пробел — PLAY; R — REC. В драм-секвенсоре цифры 1–6 — OP1–OP6, 7/8 — PITCH/GLOBAL, 9/0 — MONO/POLY, + — удалить/пауза. Для сочетаний включи удержание кнопок.

Готов к запуску. Новый проект начинается с пустых дорожек.
