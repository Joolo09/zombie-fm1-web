# Groovebox 0.8.3 — подсветка SAVE

Исправлен случай: поворот K2 меняет параметр, после чего SAVE постоянно горит.
Причиной была привязка яркой подсветки SAVE ко всем несохранённым изменениям.
Теперь SAVE кратко загорается при нажатии. Несохранённые изменения обозначены
звёздочкой `*` в заголовке экрана; состояние проекта также доступно редактору.
Нажатие SAVE сохраняет проект, системные настройки и раскладку пэдов как раньше.

Прошивка: `zombie-groovebox-0.8.3.fwsc`, identity `FM-1_63000803`.
Совместима с текущим веб-редактором Groovebox и DAW-профилями 0.8.2.
Управление и формат проектов не изменены. Sampler остаётся 0.8.0.

Проверено: сборки host, AC79 и WASM; штатный сценарий симулятора;
поворот K2, подсветка SAVE, сохранение и перезапуск на виртуальной flash;
проверки USB-установщика с симулированным устройством.
На физическом FM-1 не проверено. Это исправление одного подтверждённого
случая, а не заявление об устранении всех возможных ошибок прошивки.

Перед обновлением сохрани резервную копию проекта в редакторе.
Выбери Groovebox 0.8.3 в установщике и установи вручную.
