# Groovebox 0.9.0 beta — Hortator в дорожке 6

Пять синтезаторных дорожек сохраняют прежний звук и управление. В шестой —
восемь драм-партий Hortator: 45 моделей, 151 пресет, 64 шага, Grids, ratchet,
условия, LFO, эффекты, компрессор, motion, четыре проекта и song chain.

На FM-1: ALGO выбирает внешнюю дорожку, **SEL + PRESET** — барабан внутри шестой.
Остальные кнопки и ручки работают по схеме Hortator. В экспериментальном
веб-редакторе есть экран FM-1 и полная виртуальная панель.

**Это тестовая сборка, на физическом FM-1 не проверена.** Штатная версия по
умолчанию остаётся 0.8.3. Проблему обновления/перезапуска нельзя считать решённой
по результатам симулятора.

Перед проверкой сохраните прежний проект и держите файл 0.8.3 для возврата.
Драм-проект сохраняется отдельно через SAVE и экспортируется в `.zhkit`.
Проекты исходного Hortator FDRE не импортируются.

Из-за памяти FM-1 хвост драм-дилея хранится с 8-битным компандированием;
встроенный SAMPLE-kit заменён собственными синтетическими звуками ZOMBIE.
Синтезаторы и их эффекты не используют это сжатие. Загрузчика пользовательских
сэмплов нет. Bluetooth и глобальные настройки устройства остаются от Zombie.

Подробности, карта памяти, исходники и границы проверки:
[source/drum-suite/README.md](../source/drum-suite/README.md).
Комбинированная прошивка распространяется под GPL-3.0-only с полными исходниками.
