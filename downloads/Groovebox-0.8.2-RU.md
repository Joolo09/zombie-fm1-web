# Groovebox 0.8.2 — управление

SELECT всегда меняет BPM (30–300): все экраны, удержания и DAW Controller.
ALGORITHM — дорожка. PRESET — звук; на SEQ — банк шагов, в удержании — страница
слоя. Короткое нажатие FX / ENV / LFO / SEL / EDIT / GLO / ARP / SEQ открывает
раздел; повторное нажатие листает его страницы. У разделов есть память страниц
в текущем сеансе. HOME возвращает на первую главную страницу.

Удержание срабатывает через 180 мс; сочетание с клавишей — сразу. Отпускание
возвращает к прежнему экрану. Удерживай FX, ENV, LFO, EDIT, GLO, ARP, SEQ или
REC и нажми HOME: слой остаётся открытым (LOCK). HOME закрывает его; другая
функциональная кнопка выходит из слоя и выполняет своё действие. PLAY / REC /
SAVE также выходят из зафиксированного слоя. HOME + SEL сохраняет прежнее
переключение Standalone / DAW Synth / DAW Controller; SEL не фиксируется.
Удержание HOME по-прежнему открывает «Об устройстве / Обо мне».

SEQ + OCT− / OCT+ — банк шагов без смены октавы; первые четыре чёрные клавиши
в слое SEQ выбирают банк напрямую. EDIT + OCT− / OCT+ — Undo / Redo.
На шестой дорожке K2 выбирает инструмент кита, не заменяя уже записанный кик
на выбранном шаге. SEQ + белая клавиша добавляет/убирает выбранный инструмент
этого шага. Другие удары сохраняются, до четырёх инструментов на шаге. Нота,
сыгранная на белой клавише или через MIDI, также выбирает инструмент кита.
На синтезаторной дорожке выключение/включение шага сохраняет аккорд и длину.

В DAW Controller SELECT отправляет относительный BPM через ch16 CC116
(64=нейтрально, 65=+1, 63=−1). Установи скрипты 0.8.2 из нового ZIP:
FL использует FPT_TempoJog, Live — Song.tempo. Ноты, четыре макро-регулятора,
PLAY/REC, выбор канала и PRESET/PAN сохранены. Громкость в контроллере теперь
GLO → страница 2 → K3; K4 — панорама. Синхронизация внешнего MIDI Clock
по-прежнему подчиняется источнику темпа; для ручного темпа синтезатора выбери
внутренние часы. Автоматизация темпа и внешний sync DAW могут менять BPM хоста.
Sampler остаётся 0.8.0, с прежней схемой SELECT=громкость в DAW Controller.

Восстановлена прежняя картинка «Зомби ФМ-1» на настоящем пути app_splash:
240×240, 256 цветов, RGB565; без кадров/буферов в куче и задержек в аудио.
Использован существующий assets/splash-240.png / индексированный заголовок,
новая картинка не генерировалась. Веб-превью — реальный рендер host-приложения.

Справочник SLOOP изучен как описание работы кнопок, без копирования кода
приложения или движков: https://github.com/isod89/sloop-fm1/blob/main/GUIDE.md
Наша схема SELECT=BPM везде намеренно отличается от контекстного SELECT SLOOP.
Это не перенос всех функций SLOOP: Song, ратчеты, microtiming, p-locks и другие
отсутствующие возможности не заявляются. Новые обработчики написаны независимо.
API темпа: https://www.image-line.com/fl-studio-learning-content/fl-studio-online-manual/html/midi_scripting.htm
https://docs.cycling74.com/apiref/lom/song/#tempo

Проверено в host: девять разделов, восемь удержаний, DAW BPM и CC, память
страниц, фиксация/выход, банки без смены октавы, сохранение ударов/аккордов,
Undo, цветопиксельная сверка заставки. Скрипты DAW проверены на stub API.
Звуковой WASM побитно совпадает с 0.8.1 — синтез не изменялся. Обе сборки
компилируются, полный сброс после установки из 0.8.1 сохранён. Устройство
не прошивалось автоматически; на физическом FM-1 и в реальных DAW не проверено.
