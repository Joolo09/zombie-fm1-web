# Zombie Force 0.3.0 — принудительный запуск USB0 host

Экспериментальная сборка FM-1_62000300. Тестовые наборы намеренно НЕ запускались
по запросу пользователя. На физическом FM-1 эта версия не проверена.

Контроллер не ждёт FSDEV/LSDEV: после переключения в host отправляет USB reset
и GET_DESCRIPTOR на Full Speed. При неудаче заново инициализирует USB0 и
повторяет на Low Speed. Включение HOSTMODE всё ещё проверяется. Положительный
результат требует настоящего корректного дескриптора; отсутствие ответа не
превращается в успех. HOME отменяет, ожидания ограничены, после попытки
восстанавливается USB device. На разъём НЕ добавляется питание 5 В.

1. Установи Zombie Force 0.3.0 в отдельном /lab/ установщике.
2. Отключи ПК, оставь FM-1 включённым от аккумулятора и подключи клавиатуру
   либо USB-приёмник мыши через переходник.
3. Нажми GLO и держи PLAY 2 секунды. При BLOCKED / WAIT отпусти PLAY,
   убедись, что ПК отключён, подожди 3 секунды и повтори. HOME отменяет.
4. После результата отключи периферию, подключи ПК без перезагрузки FM-1.
   Страница /lab/force/ позволяет прочитать результат FS/LS и скачать JSON.

Без питания периферии эта попытка также может закончиться таймаутом/ошибкой.
USB-контроллер не является 5-вольтовым источником. Неизвестные GPIO и цепь
питания не переключаются. Дисковых команд, монтирования и записи файлов нет.
Для возврата к Hortator нужен его установщик. Groovebox 0.8.2 в меню возврата
устанавливает нашу музыкальную прошивку, не Hortator.

build.py компилирует только firmware, тесты и симуляторы не вызывает.
Аппаратная основа MPL-2.0, оригинальное приложение/Force/веб-отчёт MIT.
Код Lab 0.1/Host 0.2, готовые прежние пакеты и основной сайт не меняются.
